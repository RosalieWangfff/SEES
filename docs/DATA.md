# Data and external assets

Obtain datasets from their original providers and follow each provider's terms:

- MELD: https://github.com/declare-lab/MELD
- DailyDialog: http://yanran.li/dailydialog
- EmoryNLP: https://github.com/emorynlp/emotion-detection
- Upstream task implementation: https://github.com/Reason-Wang/DialogueGLP
- RoBERTa: https://huggingface.co/FacebookAI/roberta-large

The present executable workflow consumes prepared assets. Raw corpus downloads
alone are insufficient to reproduce the archived experiment protocol.

| Relative path beneath `runtime/` | Purpose |
| --- | --- |
| `baselines/assets/roberta-large/` | Local pretrained tokenizer and model |
| `baselines/DialogueGLP/data/` | Upstream and processed forecasting splits |
| `formal_model/data/*_dependency_v1/` | Aligned word features, dependency parses and manifests |
| `formal_model/data/dailydialog/` | Prepared forecasting train/validation rows |
| `baselines/glp_validation/meld_v1/` | MELD features and shared B_s42 initialization |
| `payload/external/emorynlp_public_v1/` | EmoryNLP features and shared initialization |
| `payload/external/extension_dailydialog_v1/` | DailyDialog features and extractor |
| `payload/erc_english/` | Frozen ERC metadata and associated assets |
| `results_predicted_english/<dataset>/cache/` | Historical-emotion predictions, including OOF train predictions |
| `data/stanza_resources/` | Exact parser resources required by recorded manifests |
| `glp/data/<dataset>/` | Aligned baseline train/validation inputs |
| `test_cache/<dataset>/` | Held-out historical features, generated by evaluator or restored |

`provenance/local_assets_inventory.json` lists available local asset paths and
sizes; it is an inventory, not a hosted download service or permission to
redistribute the files. The existing runtime verifies relevant asset hashes.
Download instructions and a verified prepared-asset release remain publication
work. A new raw-data pipeline would require its own reproducibility check.

No future target utterance may be sent into the history encoder. Historical
emotion predictions must retain their documented OOF/full-classifier provenance.
The MELD/EmoryNLP runs use shared supervised initialization; they are not all
independent training from scratch. DailyDialog matched training initializes fresh.
